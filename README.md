## 二、独享 vs 共享、峰值 vs 保证:这些词儿的差距比你想的大

### 独享带宽和共享带宽

简单说,**独享带宽**就是你这条管道归你一个人用,别人再怎么跑都挤不到你;**共享带宽**是一群人共用一条大管道,大家各凭本事抢。

独享的好处是稳定,坏处是贵——20Mbps 独享的价格,可能比 100Mbps 共享还高。所以市面上大多数面向个人和小团队的香港 VPS,走的都是共享路子,关键看商家**超售得狠不狠**。超售轻的,共享也能跑得很爽;超售狠的,标着 1Gbps 也能给你压成 10Mbps。

### 峰值带宽和保证带宽

这又是另一个文字游戏。**峰值带宽(Peak/Burst)** 意思是"理论最高能到这个数",但平时大概率跑不到;**保证带宽(Guaranteed)** 才是"任何时候都至少能给你这么多"。

很多便宜套餐挂的"1Gbps",其实是峰值,真跑起来可能稳定在 200–400Mbps 就不错了。这不是商家骗你,是你没看清条款。

### 流量限制和超额政策

这块坑也不少。常见的三种玩法:

1. **不限流量**:最省心,但通常带宽不会给太大,或者会通过其他方式限速。
2. **有限流量,超了限速**:比如 1TB/月,用完后降到 10Mbps 或者更惨。GoMami 这边比较狠,超了直接降到 20KB/s,基本等于断网,逼你升级套餐。
3. **有限流量,超了按 GB 计费**:这种最危险,一个不留神账单可能爆。

买之前一定要看清楚是哪种。
